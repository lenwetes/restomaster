# Code Review Gate

## Overview

Puerta de revisión obligatoria antes de merge (o antes de marcar como terminado). Evita los fallos del desarrollo asistido por IA: megadiffs ilegibles, sin pruebas, sin revisión de seguridad, y trabajo no registrado entre agentes.

## Cuándo aplica

- Fin de feature / módulo
- Antes de `git merge` / PR
- Cuando un agente reportó "listo" (verification-before-completion aplica)

## Checklist del gate (en orden)

### 1. Diff legible
- [ ] PR ≤ 400 líneas (si es más, partir)
- [ ] Cambios de una sola responsabilidad
- [ ] Sin cambios no relacionados (formato de archivos no tocados, tooling sin pedir)

### 2. Tests
- [ ] Suite verde local (`composer test` / `php artisan test`)
- [ ] Test del feature existente (no solo "no rompe lo demás")
- [ ] Migraciones corren limpias `migrate:fresh --seed`

### 3. Seguridad (nodes aplican a este proyecto)
- [ ] `laravel-security-review` aplicado sobre el diff
- [ ] `secrets-scan` sobre el diff
- [ ] `authz-rbac-check` para operaciones de dinero/estado
- [ ] `dependency-audit` si se agregó algún paquete

### 4. Calidad
- [ ] `laravel-best-practices`: estructura app/ coherente, sin controladores gordos
- [ ] `performance-audit`: sin N+1 en el diff
- [ ] `pint`/`phpstan` verdes

### 5. Coordinación (AGENTS.md)
- [ ] Cambios registrados en `coordination.md`
- [ ] No quedan `.lock` sin liberar
- [ ] Movimientos en módulos compartidos (migraciones/models/rutas/config) confirmados

## Comandos del gate

```bash
# Scope del diff
git diff --stat
# o, si git está inicializado en el repo:
git status

# Tests
composer test   # o php artisan test

# Estilo/código estático si está configurado
composer run pint -- --test
composer run phpstan
```

## Decisión del gate

| Resultado | Acción |
|-----------|--------|
| Todo verde + diff pequeño | Aprobado para merge, registrar en coordination.md |
| Falta test o hay security finding | Bloquear: corregir en el MISMO PR, no dejar cascade |
| Diff >400 líneas | Partir en PRs menores ANTES de mergear |
| Hallazgo critical/high | No mergear. Rotar/parchear y re-verificar |

## Red Flags — STOP

- "Los tests pasan local, confío" → verificar el comando, no asumir
- "Es solo el agente, yo lo reviso" → el gate corre igual para ambos agentes
- "El diff es grande pero es todo de una" → partir
- "No hubo cambios de seguridad" → se revisa, no se asume
- "No hicimos lock porque es pequeño" → regla AGENTS.md: los módulos compartidos SIEMPRE con lock

## Salida requerida

Resumen del gate: `√/✗ tests · seguridad · authz · perf · lint · coordinación` + lista de hallazgos con severidad. Bloquear si no está todo verde.
